# cursor-test

로컬 테스트용 **SQLite** DB입니다. 별도 서버 설치 없이 파일 하나로 동작합니다.

## 최초 1회 — DB 만들기

```bash
py scripts/init_db.py
```

`data/app.db`가 생성되고 샘플 `users` 테이블(5명)이 들어갑니다.

## 연결 정보 (`.env`)

| 항목 | 값 |
|------|-----|
| 종류 | SQLite |
| 경로 | `data/app.db` |

## DB Helper로 해볼 만한 요청 예시

- "테이블 목록 보여줘"
- "유저 테이블 전체 조회해줘"
- "2026년에 가입한 유저 보여줘"
- "비활성 유저만 조회해줘"
